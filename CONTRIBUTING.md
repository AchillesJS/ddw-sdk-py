# Contributing

Follow the README source setup in an isolated Python 3.11+ environment. Use synthetic or explicitly approved data; never include credentials, local databases, training artifacts, or employer/client material.

Keep changes focused and explain the problem, resulting behavior, and checks actually executed. Run the README test, lint, and type-check commands; report failures and skipped checks honestly. Changes to domain contracts, report schemas, migrations, and public interfaces need explicit design review. Preserve the decision-workspace scope.

Report suspected credentials privately to the repository owner; do not paste secret values into public issues. Licensing is unresolved or proprietary as described in the README; this file grants no additional rights.
